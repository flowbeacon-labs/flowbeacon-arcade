# Flowbeacon Arcade

A standalone home page linking to four independently hosted arcade games:

- Pixel Quest — https://flowbeacon-labs.github.io/pixel-quest/
- Little Shark — https://flowbeacon-labs.github.io/little-shark-ocean-quest/
- Coin Climber — https://flowbeacon-labs.github.io/coin-climber/
- Sweet Swap — https://flowbeacon-labs.github.io/sweet-swap-adventure/

## Publish on GitHub Pages

1. Create a new **public** repository named `flowbeacon-arcade` in `flowbeacon-labs`.
2. Upload `index.html` and `README.md` into its root directory.
3. Open **Settings → Pages → Deploy from a branch**, select **main** and **/(root)**, then Save.
4. Open https://flowbeacon-labs.github.io/flowbeacon-arcade/ after deployment completes.

This page links to independently hosted games; it does not modify any of their repositories. Players can use the browser Back button to return to the arcade. For an in-game Home button, each game's HTML would need a separate update.
